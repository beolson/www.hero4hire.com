# Create Content

Use this skill for content authored in this repository.

## Routes

- For a System Script, read [System Scripts](references/system-scripts.md) and use [the System Script template](references/templates/system-script.mdx).
- For a how-to guide, read [How-to Guides](references/how-to.md) and use [the how-to template](references/templates/how-to.mdx).
- To add a document type not yet covered here, read [Future Content Types](references/content-types.md).
- For requested revisions or when the user says “send it,” read [Review and Publish](references/review-and-publish.md).

When a document is ready for review, start the site preview with `bun dev` from `site/` and let the user interact with it.
