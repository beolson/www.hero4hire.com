# Getting started

Use this guide as the first step in your Hero4Hire journey.

## Create a project

Create a project for the work your team is ready to organize. Give it a clear name, then invite the people who will contribute to it.

## Share the context

Add the goals, decisions, and resources your team needs. Keeping that context close to the work makes every next step easier to understand.

## Keep moving

Return here as Hero4Hire grows. This documentation is designed to evolve with your team.
