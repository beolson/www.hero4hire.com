# Create a Hero4Hire project

## Overview

This guide explains how to create a Hero4Hire project so your team has a shared place to organize its work.

## Before you start

Before you create a project, decide on a clear name that describes the work it will contain.

## Create a project

1. Open Hero4Hire and select **Create project**.

2. Enter a clear, descriptive project name.

3. Add the goals, decisions, and resources that give contributors the context they need.

4. Invite the people who will contribute to the project.
